## OBD2 Scanner 1.0 🇧🇷

Primeira versão. Scanner OBD2 gratuito e de código aberto para Windows 10 e 11, para adaptadores **ELM327** (originais e clones) por USB, Bluetooth, Bluetooth LE e Wi-Fi.

### Como instalar

1. Baixe **`OBD2-Scanner-1.0.0-Windows-instalador.exe`** aqui embaixo, em *Assets*.
2. Abra o arquivo. O Windows pode avisar "O Windows protegeu o computador", porque o instalador ainda não tem assinatura digital: clique em **Mais informações → Executar assim mesmo**.
3. Abra o programa pelo menu Iniciar. Sem carro por perto? Use o **modo demonstração**.

**Sem instalar:** baixe **`OBD2-Scanner-1.0.0-Windows-portatil.zip`**, descompacte numa pasta (ou pendrive) e abra `OBD2-Scanner.exe`. As configurações ficam na pasta `OBD2-Scanner-dados`, ao lado do programa.

O arquivo `.msi` é o mesmo programa para instalação por empresas/administradores. `SHA256SUMS.txt` serve para conferir que o download não foi alterado.

### O que ele faz

- Painel ao vivo com mais de 80 parâmetros, em cartões ou mostradores, com explicação de cada um, alertas com som e computador de bordo (consumo, distância).
- Interpretação automática dos dados em português.
- Códigos de falha (ler, apagar, quadro congelado) com descrições em português e tabelas de 10 marcas; testes da central (Modo 06); monitores de prontidão; chassi (VIN); lista das centrais do carro.
- Testes de desempenho 0–100, 100–0, 40–80 e 80–120 km/h com detecção automática do início e do fim.
- Gráficos, gravação, reprodução de gravações e exportação (CSV para Excel, JSON, PNG, relatório em PDF).
- Head-up display (HUD) para o para-brisa.
- Robusto com clones: detecta travamento e reconfigura o adaptador sozinho, reconecta quando o Bluetooth cai e testa a versão real do adaptador.
- Perfis para vários carros (reconhecidos pelo chassi), unidades métricas ou imperiais, 8 temas, português e inglês.
- Só leitura: o programa nunca grava nada nas centrais do carro (apenas apaga códigos de falha quando você pede).

Guia de uso: [COMO-USAR.md](https://github.com/samuvieceli/obd2-scanner/blob/main/docs/COMO-USAR.md)

## OBD2 Scanner 1.0 🇺🇸

First release. A free, open-source OBD2 scanner for Windows 10 and 11, for **ELM327** adapters (genuine and clones) over USB, Bluetooth, Bluetooth LE and Wi-Fi.

### How to install

1. Download **`OBD2-Scanner-1.0.0-Windows-instalador.exe`** below, under *Assets*.
2. Run it. Windows may say "Windows protected your PC" because the installer is not digitally signed yet: click **More info → Run anyway**.
3. Start the program from the Start menu. No car nearby? Use the **demo mode**.

**No install:** download **`OBD2-Scanner-1.0.0-Windows-portatil.zip`**, unzip it to a folder (or USB stick) and run `OBD2-Scanner.exe`. Settings are kept in the `OBD2-Scanner-dados` folder next to it.

The `.msi` file is the same program for company/administrator deployment. `SHA256SUMS.txt` lets you check the download was not altered.

### Highlights

- Live dashboard with 80+ parameters as cards or dials, with explanations, sound alerts and a trip computer.
- Automatic plain-language interpretation of the data.
- Trouble codes (read, clear, freeze frame) with brand tables; Mode 06 test results; readiness monitors; VIN; list of the car's control units.
- Performance tests 0–100, 100–0, 40–80 and 80–120 km/h with automatic start/end detection.
- Charts, recording, playback and export (CSV, JSON, PNG, PDF report). Head-up display.
- Clone-proof: detects a frozen adapter and reconfigures it, reconnects when Bluetooth drops, tests the adapter's real version.
- Profiles for several cars (matched by VIN), metric or imperial units, 8 themes, Portuguese and English.
- Read only: it never writes to the car's control units (it only clears trouble codes when you ask).
